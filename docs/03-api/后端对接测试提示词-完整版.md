    → Word → Pandoc 流水线
    → Image/PDF → VL OCR 流水线

## 第 12 组：错误处理 & 边界测试

> 依赖：可切换环境变量或推入不同配置  
> 对接链路：各层的异常 → AppError / HTTPException → 前端错误提示

对接着：错误码体系 (23 个错误码, 7 个警告码) ↔ Pydantic 校验 ↔ FastAPI 异常处理器

**测试清单**

```
1. AI 禁用模式：
   PHYSICS_AI_ENABLED=false (或 PHYSICS_MCP_MODE=disabled)
   调用任意 AI 端点 → {"detail":{"code":"AI_DISABLED", "retryable":false}}

2. 无效 JSON 请求体 → 422 Validation Error

3. 不存在的路由 → 404

4. 数据库文件被删除后重启 → 自动重建 (initialize_database)

5. 并发请求：
   同时发 10 个 GET /search/questions → 无死锁，全部返回 200

6. Stdio 模式 — 命令不存在：
   PHYSICS_MCP_MODE=stdio, PHYSICS_MCP_VL_COMMAND="nonexistent_cmd"
   test-connection → reachable:false, "command not found on system PATH"

7. MCP 超时：
   PHYSICS_MCP_PARSE_TIMEOUT_MS=1
   调用 parse-document → {"detail":{"code":"MCP_TIMEOUT", "retryable":true}}

8. Stdio 子进程异常退出：
   PHYSICS_MCP_VL_COMMAND="python -c 'exit(1)'"
   → {"detail":{"code":"MCP_PROCESS_EXITED", "retryable":true}}

9. MCP 返回非 JSON → SCHEMA_VALIDATION_FAILED (retryable=false)

10. 未配置 HTTP client 时调用 AI：
    不推入 runtime config，直接调 POST /api/ai/analysis/generate
    → generated=false + 警告说明（降级不崩溃）

11. 超大请求体 → 413 或合理截断

12. 特殊字符 / SQL 注入 / XSS：
    GET /search/questions?query=<script>alert(1)</script>
    GET /search/questions?query='; DROP TABLE questions; --
    → 返回空结果或正常过滤，不崩溃
```

## 第 13 组：前后端全链路

> 依赖：启动前端 Vite dev server + 后端 uvicorn  
> 对接链路：React UI → fetch(API) → FastAPI → Service → Repository/Provider → 响应 → React 渲染

对接着：前端 ↔ 后端全栈（这是最终验收测试）

**测试清单**

```
1. 健康检查连通：
   前端打开首页 → Network 面板确认 GET /health 和 GET /api/mcp/status 成功

2. AI 配置页：
   填入 DeepSeek/DashScope key → 保存 → 确认 POST /api/mcp/config 成功
   → 刷新页面 → 配置仍然存在（runtime_ai_config.json 持久化）

3. 搜索流程：
   首页搜索框输入"牛顿" → 确认 GET /search/questions?search_mode=strict&query=牛顿
   → 列表渲染正确

4. 筛选器联动：
   选择模块=力学, 题型=计算题 → 确认请求参数正确传递
   → 筛选项下拉数据来自 GET /filters/facets

5. 题目详情 → 编辑 → 保存：
   点击题目 → GET /questions/{id} → 编辑 → POST review_save
   → 确认版本快照生成

6. AI 解析生成：
   题目详情页点击"生成解析" → POST /api/ai/analysis/generate
   → 解析内容渲染到页面

7. 导入文档：
   上传 .docx → Pandoc 转换 → AI 结构化 → 题目列表 → 确认导入
   → 整条流水线在 UI 上可视化

8. 导出/恢复：
   系统设置 → 导出 .zip → 下载成功
   → 另一环境导入 → 数据和图片恢复
```
