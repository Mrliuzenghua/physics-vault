# 职责边界与伪代码地图

> 状态：第一轮基线（只分析，不修改业务行为）
> 更新原则：改动一个公共模块或复杂流程时，同步更新本文件；小型纯函数以类型、函数名和单元测试为准，不在这里重复逐行解释。

## 1. 文档的粒度

成熟团队通常不会为每一个 `formatX()` 一类的小型私有函数维护一篇独立文档——那会迅速与代码脱节。更可维护的做法是分三层：

| 层级 | 记录什么 | 适用范围 |
| --- | --- | --- |
| 架构地图 | 模块边界、依赖方向、数据边界 | 全项目 |
| 伪代码卡片 | 输入、输出、步骤、副作用、失败方式 | 公开接口、复杂函数、跨模块流程 |
| 代码内说明 | 类型、短注释、测试用例 | 小型函数和实现细节 |

本文件中的“函数卡片”使用以下格式：

```text
函数：模块.函数名
职责：一句话说明其唯一目的。
输入 / 输出：调用者提供什么，得到什么。
副作用：数据库、文件、网络、缓存或全局状态；没有则写“无”。
伪代码：关键判断和步骤，不复述语法。
```

## 2. 当前系统职责图

```text
React 页面 / 组件
    ↓（HTTP + 前端状态）
FastAPI Router（参数校验、协议转换）
    ↓
Service（业务流程、编排、领域规则）
    ↓                         ↘
Repository（SQLite 读写）       MCP Gateway（模型 / 外部能力）
    ↓                         ↘
标准题库 / 审核库               文件、缓存、后台任务
```

依赖必须单向向下：页面不直接拼接后端细节；Router 不直接承载复杂业务；Repository 不调用 HTTP 或模型；Service 负责跨 Repository、MCP 与文件操作的协调。

### 数据边界

| 数据域 | 主要位置 | 允许承担的职责 |
| --- | --- | --- |
| 标准题库 | Canonical DB | 正式题目、元数据、检索与受控写入 |
| 审核工作区 | Review DB | 草稿、送审队列、导入任务与恢复状态 |
| 文件资源 | `data/` | 原始素材、导出物、缩略图缓存、日志 |
| 外部 AI 能力 | MCP | 文档解析、生成、推理与模型配置 |

## 3. 入口与装配（函数级卡片）

### 后端：`apps/api/src/physics_vault_api/app.py`

#### `_resolve_project_file(file_path)`

```text
职责：把相对项目路径安全地转换为一个真实文件。
输入 / 输出：相对路径 → 已存在且位于项目根目录内的 Path。
副作用：无；不合法时抛出 404。
伪代码：
  root = 项目根目录的规范路径
  target = 连接 root 与 file_path 后的规范路径
  若 target 不是文件，或 target 不在 root 内：返回 404
  返回 target
```

#### `_cache_response(response, max_age=86400)`

```text
职责：为文件响应补充浏览器缓存策略。
输入 / 输出：FileResponse、缓存秒数 → 同一 FileResponse。
副作用：写入 HTTP 响应头。
伪代码：若未设置 Cache-Control，则设置 public + max-age；返回响应。
```

#### `_thumbnail_cache_path(target, width)`

```text
职责：为“文件版本 + 目标宽度”计算稳定的缩略图缓存地址。
输入 / 输出：图片 Path、宽度 → WebP 缓存 Path。
副作用：读取文件元数据。
伪代码：以文件路径、修改时间、大小和宽度生成 SHA-1；拼接到 data/.cache/image-thumbs。
```

#### `_build_thumbnail(target, cache_path, width)`

```text
职责：读取原图，按宽度等比缩放并输出兼容的 WebP 缩略图。
输入 / 输出：原图路径、缓存路径、宽度 → 无返回值。
副作用：创建缓存目录并写入 WebP 文件。
伪代码：
  打开图片并应用 EXIF 方向
  等比限制到 width × (width * 4)
  若有透明通道：铺白底；否则转换为 RGB
  以统一质量参数保存为 WebP
```

#### `create_app()`

```text
职责：创建并装配整个 FastAPI 应用。
输入 / 输出：无 → 已注册中间件和业务 Router 的 FastAPI 实例。
副作用：初始化数据库；创建 ApplicationContainer。
伪代码：
  初始化数据库
  创建 FastAPI 与 CORS 配置
  注册 health、文件服务、缩略图服务这三个基础端点
  container = ApplicationContainer.build()
  逐个注册 container 提供的 Router
  返回 app
```

**边界观察：**基础文件/缩略图端点仍与应用装配放在同一文件；后续可迁为 `routers/files.py` + `services/thumbnail_service.py`，使 `app.py` 只保留应用创建和中间件装配。

### 后端：`apps/api/src/physics_vault_api/application.py`

#### `ExportWorkerContainer.build(task_queue_settings=None)`

```text
职责：为导出 Worker 组装最小依赖集合。
输入 / 输出：可选任务队列配置 → ExportWorkerContainer。
副作用：打开审核库并恢复超时任务。
伪代码：读取队列配置；建立任务仓储；恢复陈旧任务；创建导出服务；返回容器。
```

#### `WorkerContainer.build(mcp_settings=None, task_queue_settings=None, recover_stale=True)`

```text
职责：为导入 Worker 组装不包含 Web Router 的运行依赖。
输入 / 输出：MCP 与队列配置 → WorkerContainer。
副作用：可能恢复运行时 AI 配置；可能恢复陈旧任务；访问审核库。
伪代码：创建 MCP 网关；按策略恢复 AI 配置；创建任务仓储；按开关恢复任务；
         注入 Pandoc、清洗器、结构化解析器和 MCP 解析器，构造导入服务。
```

#### `ApplicationContainer.build(mcp_settings=None)`

```text
职责：唯一的 Web 应用依赖装配点。
输入 / 输出：可选 MCP 配置 → 包含 Router 所需 Repository 和 Service 的容器。
副作用：读取环境变量与运行时配置；初始化多个 Repository；可能通知 MCP 配置更新。
伪代码：
  创建 MCP Gateway 与所有 Repository
  建立共享的 QuestionSearch / QuestionWrite Service
  基于 Repository、Service、Gateway 组装各领域 Service
  返回完整容器
```

#### `ApplicationContainer.routers()`

```text
职责：以统一顺序产出已注入依赖的 API Router。
输入 / 输出：容器自身 → Router 可迭代对象。
副作用：无（创建 Router 对象）。
伪代码：按领域依次调用各 build_*_router，并传入所需 Service 或 Repository。
```

#### `_should_restore_runtime_ai_config(settings, explicit_settings)`

```text
职责：决定启动时是否向 MCP 恢复运行时 AI 配置。
输入 / 输出：MCP 设置、是否显式传入设置 → 布尔值。
副作用：读取环境变量。
伪代码：显式禁用时返回否；显式设置或 MCP 未启用时返回否；
         明确配置 MCP 模式时仅 HTTP 模式允许；其余情况允许。
```

**边界观察：**`ApplicationContainer` 同时承担依赖声明、实例创建、启动恢复和 Router 注册，已是后端主要的“装配热点”。这是合理的 composition root，但 40+ 依赖意味着可按领域拆成 `build_import_domain()`、`build_question_domain()`、`build_lesson_domain()` 等私有装配函数，保持总入口薄而可读。

### 前端入口

#### `main.tsx`（模块初始化）

```text
职责：创建 React 根节点，提供全局查询缓存配置。
副作用：挂载页面到 DOM；全局加载 KaTeX 与基础样式。
伪代码：创建 QueryClient 默认缓存策略；用 StrictMode 和 QueryClientProvider 包裹 App；渲染到 #root。
```

#### `appRoutes`（`apps/web/src/appRoutes.tsx`）

```text
职责：定义 URL 到懒加载页面或兼容跳转的映射。
输入 / 输出：路由路径 → 页面元素。
副作用：首次进入某页面时按需加载其代码。
伪代码：声明各页面 lazy import；把有效路径映射到页面；把废弃路径重定向到替代入口。
```
