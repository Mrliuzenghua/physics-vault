# 私有化高中物理题库系统｜完整需求文档

文档版本：V2.1  
更新时间：2026-07-26

## 一、项目概述

### 1.1 项目名称
私有化高中物理题库与组卷讲题系统

### 1.2 项目目标
建设一套本地私有化运行的高中物理题库系统，支持图片、PDF、Word（docx）等试题资料批量导入，完成试题切分、OCR/多模态识别、结构化校对、题库存储、智能检索、组卷排版、课堂讲题与讲义打印输出。

系统应满足教师从“录题”到“备课”再到“授课”和“打印”的完整闭环，所有数据默认保存在本地，所有 AI 能力统一通过 MCP（Model Context Protocol）接口调用。

### 1.3 目标用户
1. 高中物理教师
2. 教研组内个人备课教师
3. 需要长期沉淀专题题库、讲义模板、讲题素材的教学人员

### 1.4 产品定位
本系统定位为“教师本地私有化题库工作台”，不是在线刷题平台，不是公有云 SaaS，不以学生端练习系统为首期目标。

产品核心能力不是单纯存题，而是围绕以下六类高频工作台建立完整链路：
1. 文档导入与批量识别工作台
2. OCR/结构化校对工作台
3. 单题精修详情页
4. 题库主列表工作台
5. 组卷与可视化排版工作台
6. 课堂授课播放工作台

### 1.5 首期建设原则
1. 本地优先
2. 私有数据优先
3. AI 可插拔
4. 结构化数据优先
5. 批量效率与单题精修并重
6. 题库、讲义、课堂展示共用同一套标准数据源
7. 所有 AI 结果默认需经过校验或人工确认后才能进入正式题库

### 1.6 首期明确不做
1. RAG 向量检索
2. 多用户权限系统
3. 云端同步
4. 学生端刷题 App
5. 自动生成受力图、电路图
6. 导出 LaTeX 试卷
7. 在线分享公共链接

## 二、业务闭环与核心价值

### 2.1 核心业务闭环
文件导入  
→ 自动切题 / OCR / 多模态识别  
→ 结构化校对  
→ 单题精修  
→ 入库  
→ 检索筛题  
→ 加入选题篮  
→ 模板化组卷  
→ 自动排版 / 手动微调  
→ 输出课堂讲题页 / A4 讲义页  
→ 浏览器直接预览、授课、打印

### 2.2 核心价值
1. 降低教师录题和整理题库的时间成本
2. 让题目数据真正结构化，可长期复用
3. 让筛题、组卷、讲题、打印基于同一套题目资产完成
4. 通过本地部署和可关闭 AI 模式保障数据私密性
5. 通过批量工作台和精修工作台同时兼顾效率与质量
6. 通过批量 AI 标注能力降低后期补知识点、分类、标签的人工成本

## 四、系统角色与使用场景

### 4.1 用户角色
首期默认单用户使用，不做复杂权限系统。

角色定义：
1. 教师
2. 系统

### 4.2 核心使用场景
1. 教师导入一套扫描试卷，批量识别为结构化题目
2. 教师批量修正题号、公式、答案、知识点后入库
3. 教师按知识点、难度、年份检索专题题目
4. 教师将题目加入选题篮并按模板生成讲义
5. 教师在页面中微调排版后直接打印
6. 教师上课时按题干、答案、解析逐层展示并白板批注
7. 教师对旧题库批量补充知识点、分类、标签和目录归属

## 五、核心约束

### 5.1 AI 与协议约束
1. 所有 AI 调用统一通过 MCP 协议
2. 至少拆分为视觉模型 MCP 服务与文本模型 MCP 服务两类
3. 文档解析、试题解析、知识点生成、批量 AI 标注复用同一套 MCP Client 调度框架
4. 必须支持一键关闭全部 AI 调用

### 5.2 数据与存储约束
1. 所有数据默认本地存储
2. 题图、表格截图、原始文档独立保存在文件系统
3. 数据库仅保存相对路径，不保存二进制图片
4. 公式统一采用 LaTeX
5. 系统内部数据交换统一采用 JSON

### 5.3 运行环境约束
1. 支持 Windows
2. 支持 Mac mini M4
3. 支持离线运行
4. 浏览器输出需兼容 Windows Chrome 与 macOS 常用浏览器打印

### 5.4 日志与进程约束
1. MCP 服务进程禁止向标准输出打印调试日志
2. 日志统一写本地文件
3. 主程序退出时自动回收 MCP 子进程

## 七、模块需求

### 7.1 文档导入与批量识别工作台
目标：将图片、扫描卷、原生 PDF、docx 等资料导入系统，并以批量方式完成页面预处理、题目切分、OCR/多模态识别和初步结构化输出。

支持格式：
1. jpg
2. jpeg
3. png
4. webp
5. pdf
6. docx

导入方式：
1. 单文件导入
2. 多文件批量导入
3. 文件夹导入
4. 拖拽导入

关键能力：
1. 导入批次 `import_batch_id`
2. 原生电子文档管线
3. 图像类文档管线
4. 切题容器机制
5. 三栏批量识别工作台
6. 单题识别 / 当前页识别 / 全批次识别 / 失败重试
7. 批量规则应用

题块状态：
1. `待切题`
2. `待识别`
3. `识别中`
4. `已识别`
5. `识别异常`
6. `已确认`
7. `已入库`

### 7.2 OCR/结构化校对工作台
目标：对批量识别后的中间结果进行结构化修正、统一规则处理与批量入库前校验。

关键能力：
1. 中间结构化编辑协议
2. 三栏校对工作台
3. 题号、题干、选项、答案、解析、知识点、标签、来源、年份、图片标记编辑
4. LaTeX 清洗与 OCR 错词替换
5. 撤销、恢复、重置、保存草稿、保存并下一题
6. 入库前校验
7. 部分入库与批量入库

### 7.3 单题精修详情页
目标：处理复杂公式题、图像题、实验题、表格题等难题，完成高质量人工校对与最终确认。

关键能力：
1. 左侧章节导航、中部结构化编辑、右侧原题预览、最右相邻题导航
2. 题干、答案、解析、知识点、物理模型、实验类别、图像说明精修
3. 原题缩放、局部放大、联动高亮
4. 提取配图、提取表格、修正图文绑定
5. 保存草稿、保存并下一题、返回批量工作台

### 7.4 数据库与素材管理
目标：为题库、目录、关系、模板、讲义、知识点缓存和素材文件提供本地持久化存储。

核心数据对象：
1. 题目 `questions`
2. 题目图片 `question_figures`
3. 标签 `question_tags`
4. 导入批次 `import_batches`
5. 目录 / 合集 `collections`
6. 题目关系 `question_relations`
7. 选题篮 `basket_items`
8. 模板 `templates`
9. 讲义布局项 `layout_items`
10. 知识点缓存 `knowledge_cache`
11. AI 批处理任务 `ai_batch_tasks`
12. 任务日志 `task_logs`

### 7.5 目录、合集与题库主列表工作台
目标：作为教师日常筛题、预览、关联、导出和加入组卷篮的核心页面。

关键能力：
1. 目录树管理、专题合集、试卷合集、自定义集合
2. 多条件检索：关键词、标题、题号、年份、来源、题型、难度、知识点、标签、导入批次、收藏、错题、ID、相似题、智能查询
3. 题目卡片展示：序号、题号、题干摘要、录入时间、知识点标签带、状态、快捷操作
4. 单题快捷操作：答案、解析、分享、导出、白板、关联、更多、加入选题篮
5. 批量操作：改标签、改目录、收藏、删除、加入选题篮、重生成解析、补来源、改知识点、打开批量 AI 标注页

### 7.6 批量 AI 元数据生成工作台
目标：对已入库或待入库题目批量补充和修正结构化信息，如知识点、分类、标签、目录归属、答案等。

关键能力：
1. 当前选中 / 当前页 / 当前筛选结果 / 当前目录 / 当前选题篮范围处理
2. 可生成字段：知识点、标签、目录、分类、答案、题型、年份、来源、难度、物理模型、实验类别
3. 参考大纲生成 / AI 自动生成 / 枚举约束生成 / 规则迁移生成
4. 约束配置：知识点树、分类枚举、目录树、标签候选集
5. Prompt 配置能力
6. 预览、差异确认、部分字段回填、部分题目回填
7. 任务记录、失败重试、回填审计

### 7.7 选题篮、组卷与模板系统
目标：支持教师跨目录、跨筛选结果累积选题，并基于模板形成讲义或课堂材料。

关键能力：
1. 选题篮跨目录累积
2. 排序、移除、批量清空、保存草稿
3. 模板区块：标题区、知识点区、例题区、习题区、总结拓展区、页眉页脚区
4. 知识点静态模式与动态 AI 模式
5. 知识点缓存

### 7.8 可视化排版与讲义输出工作台
目标：将选题篮中的结构化题目渲染为可打印讲义，并支持自动排版与手动微调。

关键能力：
1. A4 / A3、纵向 / 横向、分页与缩放预览
2. 内容盒子：题目、文本、知识点、图片、分隔盒子
3. 自动排版与手动微调
4. 题目禁止跨页、手动分页、题图替换、KaTeX 渲染
5. 学生版 / 教师版切换

### 7.9 课堂授课播放工作台
目标：将题目或讲义内容转为可授课展示的课堂页面，支持逐题讲解、分层显示与白板批注。

关键能力：
1. 全屏授课、上一题/下一题、跳转题号、自动播放、倍速
2. 题干 / 答案 / 解析 / 知识点总结分层展示
3. 简易白板与临时批注
4. 查看关联题、相似题、知识点、讲义页

### 7.10 试题 AI 解析生成模块
目标：为题目生成教学可用的标准解析内容，并支持多风格输出和缓存复用。

解析固定结构：
1. 审题分析
2. 解题思路
3. 规范解题步骤
4. 最终结论
5. 易错警示
6. 拓展设问

风格：
1. `classroom_brief`
2. `self_study_full`
3. `exam_standard`

### 7.11 MCP AI 调度模块
目标：统一封装所有 AI 请求，屏蔽不同模型来源差异。

AI 职责分层：
1. 识别型 AI
2. 生成型 AI
3. 标注型 AI

## 九、异常与边界场景

1. 文件损坏、格式不支持、图片模糊、页面过多
2. 切题错误、OCR 丢字、公式识别错误、图文绑定错误、JSON 不合法
3. 关键字段缺失、重复题号、图片失联、知识点缺失
4. AI 标注结果越界、id 不匹配、误覆盖人工数据
5. 图片缺失、LaTeX 渲染失败、打印分页异常

系统处理原则：
1. 单页失败不拖垮整批任务
2. 单题异常不阻塞其余题目入库
3. 所有异常需可见、可追踪、可重试
4. AI 结果默认先校验、后预览、再确认写回
