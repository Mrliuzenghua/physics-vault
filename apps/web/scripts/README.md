# 前端构建脚本

`npm run check:bundle` 会读取 Vite 生成的 `dist/.vite/manifest.json`，列出所有超过 200 KiB 的压缩后 JavaScript 资源，并按加载方式执行预算检查：

- 初始应用资源：单块不得超过 275 KiB（当前 KaTeX 数学渲染块约 253 KiB，预留 9% 增长空间）。
- 常规按需资源：单块不得超过 450 KiB。
- 已批准的重型按需引擎：Paged.js 不得超过 600 KiB，PDF.js worker 不得超过 2500 KiB。它们只在文档分页或 PDF 预览动作中下载，因此在报告中会明确标注，不会掩盖初始加载回归。

生产构建会自动运行该检查。新增超过预算的资源必须先完成拆分；只有确实保持按需加载、且有明确用户动作边界的运行时引擎才可以增加具名例外。
